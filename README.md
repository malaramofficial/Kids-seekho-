# 🌈 Kids Seekho

छोटे बच्चों के लिए खेल-खेल में सीखने और writing/tracing practice करने वाला mobile-first web app.

## अभी उपलब्ध
- 🔤 English A–Z
- 🔢 Numbers 1–20
- अ से ह तक हिंदी अभ्यास
- 🔺 Shapes practice
- ✍️ Touch/pointer tracing canvas
- 🔊 Pronunciation using browser speech synthesis
- ⭐ Practice feedback and local progress
- 📱 Mobile-first, large touch targets
- 🚫 No ads and no external dependency required

## चलाना
`index.html` खोलें या GitHub Pages से publish करें।
